# Cashora AI 💰

**Predict Cash. Prevent Shortfalls. Grow Smarter.**

Cashora AI is an AI-powered cash flow prediction and decision support platform designed to help small businesses track their finances, anticipate potential cash shortages, and make informed decisions.

### Core Features
- Cash flow dashboard and transaction management
- Upcoming payment and overdue invoice tracking
- Cash flow forecasting
- AI-assisted financial insights
- What-if financial scenario analysis

### Tech Stack
React · Supabase · AI API · GitHub · Vercel

### Project Status
🚧 In development

### Goal
Build a practical, user-friendly financial decision-support tool for small businesses.
